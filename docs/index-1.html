Scope and limitations

The check started from an already extracted and hash-verified retail XBE. It did not repeat ISO extraction or the top-level ISO provenance step. No gameplay, first-launch GUI, Wine/Proton, or clean-machine installation test was performed for this documentation/source-packaging change. The separate historical full suite baseline remains in maintenance validation and stale-comment cleanup; it was not rerun here.

The compiled executables, generated game C, extracted input, full build logs, and test scratch outputs stay outside the public source package. Passing these checks does not grant rights to supplied artwork/audio or establish legal clearance. Preserve the dependency notices.
