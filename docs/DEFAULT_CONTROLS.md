# Default keyboard controls

New profiles use these QWERTY bindings. Existing players keep their saved rebinds and the old defaults for any actions they have not rebound. To adopt the new defaults in an existing profile, use Controls > Rebind Controls > Keyboard / Mouse > select a context > Reset These Binds. Reset each context you want to update; it does not change other contexts or controller bindings.

Mouse Aim starts enabled for new profiles. Existing Mouse Aim settings are preserved; changing bindings with Reset These Binds does not toggle Mouse Aim.

## On foot

| Action | Input |
| --- | --- |
| Move | WASD |
| Fire / throw grenade | Left / right mouse button |
| Reload / jump | R / Space |
| Melee / use | Middle mouse button / E |
| Switch weapon / grenade | Wheel up / down |
| Crouch / aim or scope | Left Ctrl / Q |
| Support item up / down | Mouse button 5 / 4 |
| Flags / shop | Left / right arrow |
| Pause / PDA | Escape / Tab |

In scope view, wheel up/down zooms and left mouse fires. Q exits scope.

## Vehicles

| Action | Helicopter | Car | Tank |
| --- | --- | --- | --- |
| Move | WASD | WASD | WASD |
| Fire | Left mouse | Right mouse (rider fire) | Left mouse |
| Ascend / descend | Space / R | — | — |
| Handbrake | — | Space | — |
| Horn | Middle mouse | Middle mouse | Middle mouse |
| Exit / disembark | E | E | E |
| Player exit | Mouse button 5 | Mouse button 5 | Mouse button 5 |
| Eject passengers | Mouse button 4 | Mouse button 4 | Mouse button 4 |
| Change weapon | Wheel up | — | Wheel up |
| Retract / deploy winch | F / V | — | — |

Helicopter mouse button 5 also retains the original secondary-fire/exit behavior. Pause and PDA use Escape and Tab in vehicles too.

## Menus and PDA

| Action | Input |
| --- | --- |
| Menu navigation / PDA map pan | WASD |
| Confirm | Space |
| Back / decline side contract | R |
| Previous / next PDA tab | Q / E |
| Close PDA | Tab |
| Select support option | E |

Other unspecified controls retain their existing defaults. All bindings can be edited separately in the Controls menu.
